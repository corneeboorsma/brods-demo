Van idee naar website met Claude

Een stap-voor-stap conversatie — Brodshoes Pasen 2026 bestellijst

Wat is dit document?
Dit is een uitgeschreven conversatie tussen een gebruiker en Claude (een AI-assistent van Anthropic). Het laat zien hoe je met eenvoudige vragen en instructies — zonder te kunnen programmeren — een complete webpagina bouwt, stijlt en publiceert op het internet.

Hoe lees je dit?
🔴 Rood blok = wat de gebruiker vroeg  |  🟦 Blauw blok = wat Claude antwoordde  |  🟢 Groen blok = wat Claude concreet deed
Stap 1 — Het project starten
Gebruiker

We hebben een project gemaakt met een uitnodiging, ken je dit nog?

Claude

Ja, ik ken het project! Het is een aanmeldpagina voor het verjaardagsfeest van Cornee (Cornee wordt 40). Datum: 2 oktober, vanaf 20:00, op Olieslager 42. Er is ook een QR-code gegenereerd en op een uitnodigingsafbeelding geplakt.

Wat deed Claude
Claude las de bestaande bestanden in de projectmap (index.html, qrcode.png, uitnodiging_definitief.png) en gaf een samenvatting van het vorige project.

Gebruiker

Juist, we gaan een kopie hiervan maken voor een POC... Bestellijst voor Pasen 2026 voor het Brodshoes. Ik geef je een link die je moet checken voor de content. Maar let op: het is een nieuw project, maak de oude niet veranderen.

Gebruiker

Claude

De website heeft een warme, elegante restaurantstijl: wit/crème achtergrond, donkere tekst, verfijnd serif lettertype, warme food-fotografie. Meer dan 45 jaar traditie. Ik ga de pagina stylen op basis van die sfeer: wit/crème basis, donkerbruin/warme aardetinten, serif koppen, strak en gastvrij.

Wat deed Claude
Claude analyseerde de Brodshoes website automatisch: kleuren, sfeer, typografie en beeldtaal — en vertaalde dit naar een ontwerpbeslissing voor de nieuwe pagina.
Tip voor beginners: Stuur gewoon een URL van een website die je mooi vindt. Claude analyseert de stijl en past die toe.

Stap 9 — Publiceren op GitHub Pages
Gebruiker

Kun je deze zetten in GitHub Pages? https://github.com/corneeboorsma/brods-demo/settings/pages

Claude

Ik kan dit doen, maar ik heb je bevestiging nodig omdat het naar een externe repo pusht. Na akkoord voerde ik de git-commando's uit.

Wat deed Claude
Na akkoord van de gebruiker voerde Claude de volgende commando's uit:

git init → git repository aanmaken
git add . → alle bestanden klaarzetten
git commit -m "..." → wijzigingen vastleggen
git remote add origin ... → koppelen aan GitHub
git push -u origin main → uploaden naar GitHub

De pagina is daarna bereikbaar via https://corneeboorsma.github.io/brods-demo/ na activatie van GitHub Pages.
Tip voor beginners: Claude vraagt altijd bevestiging voordat hij iets naar buiten pusht (naar GitHub of andere externe diensten). Zo houd je altijd controle.
Stap 10 — Kleine correcties doorvoeren
Gebruiker

Vers bereid, af te halen in Almelo → afhalen is in Rijssen
Ook de titel aanpassen, Almelo vervangen voor Rijssen

Claude

Alle vermeldingen van Almelo vervangen door Rijssen en direct gepusht naar GitHub.

Wat deed Claude
Claude zocht alle voorkomens van "Almelo" in de HTML (grep), verving ze allemaal tegelijk met de replace_all functie, en pushte de wijziging direct naar GitHub met een duidelijke commit message.
Stap 11 — Tijdslot toevoegen
Gebruiker

Maak een stap 4 aan waarbij de mensen een tijdslot van een half uur kunnen aangeven en push naar git

Claude

Stap 4 toegevoegd met 4 tijdslots als klikbare knoppen: 14:00–14:30, 14:30–15:00, 15:00–15:30, 15:30–16:00. Het gekozen tijdslot staat in de bevestigingspagina en wordt meegestuurd naar Formspree.

Wat deed Claude
Claude voegde een nieuwe sectie toe met radio-knoppen gestyled als selecteerbare tijdblokken (rood bij selectie, passend bij de Brodshoes stijl). Het tijdslot werd ook verwerkt in de JavaScript submit-logica en de bevestigingstekst. Direct gepusht naar GitHub.
Stap 12 — Achtergrondkleur aanpassen
Gebruiker

Die kleur is een warme crème/zand tint — ongeveer #e8dcc8. Ik pas de achtergrond aan en push.

Wat deed Claude
Claude herkende de kleur uit het screenshot, vertaalde dit naar een hex-kleurcode, paste de CSS variabele --teal-dark aan en pushte de wijziging direct naar GitHub.
Tip voor beginners: Je hoeft geen kleurcode te kennen of op te zoeken. Stuur gewoon een screenshot of foto van de kleur — Claude bepaalt de juiste code.
